# Chesslab — frontend

Next.js (App Router, TypeScript, Tailwind CSS) frontend for Chesslab. See the
[repo root README](../README.md) for what the app does, and [`CLAUDE.md`](CLAUDE.md) (gitignored,
local-only) for implementation detail.

```bash
npm install
npm run dev      # dev server on :3000, talks to the backend on :8080
npm run build    # production build
npx tsc --noEmit # type check
npm run test     # vitest
```
